# nodeBook

[**nodeBook**](https://nodebook.co.in) is an online deployment of [hedgedoc-nb](https://github.com/gnowgi/hedgedoc-nb), based on the cutting-edge version of [HedgeDoc](https://hedgedoc.org/). The project extends HedgeDoc's real-time collaborative markdown editor into a notebook for authoring and exploring **knowledge graphs in plain markdown** — letting users compose notes, build links between concepts, and treat the resulting structure as a queryable graph without leaving the writing surface.

## What is nodeBook?

nodeBook is a collaborative writing-and-thinking environment. It keeps everything HedgeDoc users already know — multi-user editing in markdown, syntax highlighting, presentation mode, embeddable media — and adds the abstraction the [Gnowledge Lab](/index.html) has pursued for over two decades: **knowledge as a graph of typed relations**, expressed and revised in the same lightweight notation as everyday notes.

Its goal is to make the structuring of knowledge accessible from where people already think and write, rather than behind a separate ontology-editor.

## Relationship to other lab projects

- **[hedgedoc-nb](https://github.com/gnowgi/hedgedoc-nb)** — the source code maintained by [Nagarjuna G.](/team/nagarjuna-g.html); a TypeScript fork that tracks upstream HedgeDoc 2.x.
- **[GNOWSYS / gstudio](/projects/gnowsys.html)** — the lab's earlier framework for graph-based knowledge representation. nodeBook complements GNOWSYS by lowering the barrier to capturing graph-structured content during ordinary writing.
- **[Concept Mapping research](/projects/conceptmapping.html)** — the methodological backbone for how relations between concepts are represented in lab work.
